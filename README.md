# Nashville Housing Data Cleaning

## Project Overview
Cleaned and transformed Nashville housing data using SQL Server to improve data quality and prepare it for further analysis.

## Tools & Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Data Cleaning Process
- Standardized date formats.
- Handled missing property addresses using self-joins.
- Split property addresses into separate columns.
- Standardized Yes/No values.
- Identified duplicate records using ROW_NUMBER().

## SQL Skills Demonstrated
Self-Joins, CTEs, Window Functions, CASE Statements, String Functions, Data Type Conversion, and Data Transformation.
